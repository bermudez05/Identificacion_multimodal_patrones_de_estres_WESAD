Capítulo 1. Introducción

1.1 Propósito del manual

Este manual tiene como objetivo explicar, de forma progresiva y rigurosa, cómo una señal fisiológica registrada por sensores puede transformarse en un conjunto de features útiles para construir modelos de aprendizaje automático orientados a la detección del estrés.

No se limita a presentar definiciones. Cada técnica será explicada desde su fundamento fisiológico, matemático y computacional, mostrando cómo se conecta con las señales del conjunto de datos WESAD y qué información aporta para la clasificación del estrés.

1.2 ¿Qué es una señal fisiológica?

El cuerpo humano produce continuamente fenómenos eléctricos, mecánicos, térmicos y químicos. Muchos de estos fenómenos pueden registrarse mediante sensores especializados y convertirse en una secuencia ordenada de valores numéricos.

A esta secuencia se le denomina señal fisiológica.

Una señal fisiológica no representa un único instante, sino la evolución temporal de un proceso biológico. Cada valor corresponde a una medición realizada en un momento específico.

Por ejemplo, el electrocardiograma (ECG) registra la actividad eléctrica del corazón. Si un sensor adquiere datos a 700 Hz, significa que obtiene 700 muestras por segundo. En una ventana de 60 segundos se generan aproximadamente 42 000 muestras.

Estas muestras, observadas de manera aislada, tienen poco significado. Sin embargo, cuando se analizan conjuntamente describen el comportamiento fisiológico del organismo.

1.3 ¿Por qué estudiar señales fisiológicas?

Las señales fisiológicas permiten observar procesos internos imposibles de percibir directamente.

Cuando una persona experimenta estrés se activan mecanismos regulados principalmente por el sistema nervioso autónomo. Como consecuencia pueden producirse cambios en:

  • la frecuencia cardíaca;
  • la conductancia eléctrica de la piel;
  • la respiración;
  • la actividad muscular;
  • la temperatura periférica;
  • el movimiento corporal.

Cada señal refleja una parte distinta de la respuesta fisiológica. Por ello, el análisis conjunto de varias señales ofrece una representación más completa del estado del individuo.

1.4 El conjunto de datos WESAD

WESAD (Wearable Stress and Affect Detection Dataset) es uno de los conjuntos de datos de referencia para la investigación en detección automática del estrés.

Cada participante dispone de un archivo independiente que contiene:

  • señales fisiológicas;
  • etiquetas experimentales;
  • información del sujeto.

En este manual se trabajará con las señales registradas mediante el dispositivo RespiBAN:

  • ECG
  • EDA
  • EMG
  • Respiración
  • Temperatura
  • Acelerómetro

Las siguientes secciones profundizarán en cada una de estas señales y explicarán cómo se transforman en características numéricas mediante distintas técnicas de procesamiento.

1.5 ¿Qué es una feature?

Una feature es una medida numérica que resume una propiedad relevante de una señal fisiológica.

Mientras una ventana puede contener decenas de miles de muestras, una feature sintetiza una característica concreta, por ejemplo:

  • media;
  • desviación estándar;
  • energía;
  • frecuencia dominante;
  • entropía;
  • dimensión fractal.

El objetivo de las features es conservar la información importante reduciendo drásticamente la cantidad de datos que debe procesar un algoritmo de aprendizaje automático.

1.7 ¿Por qué una señal cruda no es suficiente?

Una de las primeras preguntas que surgen al comenzar a trabajar con señales fisiológicas es por qué no utilizar directamente los miles de valores registrados por los sensores para entrenar un modelo de aprendizaje automático.

La respuesta está relacionada con la naturaleza de las señales biológicas. Aunque contienen una enorme cantidad de información, también presentan ruido, redundancia y variaciones que no siempre son relevantes para el problema que se desea resolver.

Por ejemplo, una ventana de ECG de 60 segundos registrada a 700 Hz contiene aproximadamente 42 000 muestras. Si además se analizan seis señales simultáneamente (ECG, EDA, EMG, Respiración, Temperatura y ACC), una única ventana supera fácilmente las 250 000 muestras.

Trabajar directamente con semejante volumen de datos incrementa el costo computacional y dificulta que muchos algoritmos identifiquen patrones fisiológicos relevantes.

Por ello, en lugar de utilizar la señal completa, se calcula un conjunto reducido de descriptores llamados features.

1.8 La idea fundamental de una feature

Una feature puede entenderse como un resumen matemático de una propiedad específica de la señal.

Supongamos que dos personas caminan durante un minuto. El acelerómetro registrará miles de valores distintos para cada una. Sin embargo, si calculamos la media de la aceleración, su desviación estándar, la energía y la frecuencia dominante, obtenemos una descripción mucho más compacta del movimiento realizado.

Las features cumplen precisamente esta función: condensar información compleja en variables numéricas que conservan el comportamiento fisiológico más importante.

1.10 El papel del preprocesamiento

Antes de calcular cualquier característica es necesario preparar la señal.

Dependiendo del tipo de sensor pueden existir:

  • ruido eléctrico;
  • artefactos por movimiento;
  • variaciones de la línea base;
  • pérdidas temporales de señal;
  • saturaciones del sensor.

El preprocesamiento tiene como objetivo reducir estos problemas sin eliminar la información fisiológica relevante.

En capítulos posteriores se estudiarán técnicas como:

  • filtrado digital;
  • normalización;
  • eliminación de tendencia;
  • interpolación;
  • suavizado.

      |--------------60 s--------------|

            |--------------60 s--------------|

2.1 Introducción

El electrocardiograma (ECG) es una de las señales fisiológicas más estudiadas en medicina, ingeniería biomédica y ciencia de datos. Su importancia radica en que registra, de forma no invasiva, la actividad eléctrica que controla la contracción del corazón.

Aunque habitualmente se relaciona con el diagnóstico de enfermedades cardíacas, el ECG también permite estudiar procesos fisiológicos asociados al sistema nervioso autónomo, como el estrés, la relajación, la carga cognitiva y la respuesta emocional.

En WESAD, el ECG constituye una de las principales fuentes de información para extraer features relacionadas con la frecuencia cardíaca y la variabilidad del ritmo cardíaco (HRV).

2.2 ¿Qué es realmente el corazón?

Muchas personas imaginan el corazón únicamente como una bomba que impulsa sangre. Sin embargo, desde el punto de vista fisiológico, el corazón también puede entenderse como un sistema eléctrico altamente organizado.

Cada latido comienza con un impulso eléctrico. Ese impulso viaja por un conjunto especializado de células capaces de generar y conducir electricidad. Solo después de esta activación eléctrica ocurre la contracción mecánica que bombea la sangre.

En otras palabras:

Impulso eléctrico
        ↓
Activación del músculo
        ↓
Contracción
        ↓
Bombeo de sangre

Por esta razón el ECG registra primero la actividad eléctrica y no el movimiento del corazón.

Las aurículas reciben la sangre, mientras que los ventrículos la expulsan hacia la circulación pulmonar y sistémica.

Para que el bombeo sea eficiente las cuatro cavidades deben contraerse siguiendo una secuencia precisa. Esa sincronización depende del sistema eléctrico cardíaco.

2.4 El sistema de conducción eléctrica

El impulso eléctrico se propaga siguiendo un recorrido prácticamente constante.

flowchart TD
A[Nodo sinoauricular (SA)]
-->B[Aurículas]
-->C[Nodo auriculoventricular (AV)]
-->D[Haz de His]
-->E[Ramas derecha e izquierda]
-->F[Fibras de Purkinje]
-->G[Ventrículos]

Cada estructura cumple una función específica.

Nodo sinoauricular (SA)

Es el marcapasos natural del corazón.

Genera espontáneamente impulsos eléctricos entre 60 y 100 veces por minuto en condiciones normales.

Nodo auriculoventricular (AV)

Introduce un pequeño retraso que permite completar el llenado de los ventrículos antes de que estos se contraigan.

Haz de His y fibras de Purkinje

Distribuyen el impulso eléctrico rápidamente por ambos ventrículos para producir una contracción coordinada.

2.5 ¿Qué registra realmente el ECG?

El ECG no registra sangre, presión ni movimiento.

Registra diferencias de potencial eléctrico producidas cuando millones de células cardíacas se despolarizan y repolarizan casi simultáneamente.

Cada punto de la señal representa el voltaje medido entre electrodos colocados sobre el cuerpo.

Por tanto, el ECG es una representación temporal de la actividad eléctrica del corazón.

2.6 ¿Qué significa despolarización?

Las células cardíacas mantienen una diferencia de carga eléctrica entre el interior y el exterior de su membrana.

Cuando reciben un estímulo eléctrico esa diferencia cambia rápidamente.

A este fenómeno se le denomina despolarización.

Posteriormente las células recuperan su estado inicial mediante un proceso denominado repolarización.

Estos cambios eléctricos son precisamente los que producen la señal ECG.

2.7 Relación con el estrés

El estrés activa el sistema nervioso simpático.

Como consecuencia suelen observarse:

  • incremento de la frecuencia cardíaca;
  • disminución de la variabilidad entre latidos;
  • cambios en algunos intervalos temporales;
  • modificaciones en la regulación autonómica.

Estas alteraciones no siempre son visibles directamente sobre la señal cruda. Por ello, en capítulos posteriores se estudiarán técnicas como HRV, análisis temporal, espectral y no lineal para cuantificar estos cambios mediante features.

2.8 El ciclo cardíaco

Cada latido cardíaco corresponde a un ciclo completo de eventos eléctricos y mecánicos. El ECG registra únicamente la parte eléctrica, pero esta precede y coordina la contracción del músculo cardíaco.

Un ciclo normal puede representarse de manera simplificada así:

Reposo → Despolarización auricular → Despolarización ventricular
      → Repolarización ventricular → Reposo

El proceso se repite cientos de miles de veces al día con una extraordinaria precisión.

2.10 Onda P

La onda P representa la despolarización de las aurículas.

Cuando el nodo sinoauricular genera un impulso eléctrico, este se propaga por ambas aurículas provocando su contracción. Esa propagación produce una pequeña elevación en el ECG.

Características generales:

Propiedad Valor aproximado
Duración 80–110 ms
Amplitud Baja
Origen Aurículas

En estudios de estrés normalmente no es la onda más utilizada para la extracción de features, pero resulta esencial para comprender el ciclo cardíaco completo.

2.11 Complejo QRS

El complejo QRS corresponde a la despolarización de los ventrículos.

Es el componente de mayor amplitud del ECG porque los ventrículos contienen mucha más masa muscular que las aurículas.

El complejo se divide en tres partes:

  • Q: primera deflexión negativa.
  • R: primera deflexión positiva.
  • S: deflexión negativa posterior.

El pico R es especialmente importante porque sirve como referencia para calcular la frecuencia cardíaca y la variabilidad entre latidos.

2.12 Onda T

La onda T representa la repolarización ventricular.

Durante esta fase las células recuperan su estado eléctrico inicial y quedan preparadas para un nuevo ciclo.

Aunque suele presentar una amplitud menor que el complejo QRS, también contiene información clínica relevante.

2.13 Intervalos del ECG

Además de las ondas, el ECG contiene intervalos temporales.

Intervalo PR

Corresponde al tiempo que tarda el impulso en viajar desde las aurículas hasta los ventrículos.

Intervalo QT

Representa la duración total de la activación y recuperación eléctrica ventricular.

Intervalo RR

Es el tiempo transcurrido entre dos picos R consecutivos.

▼                ▼

Este intervalo constituye la base de la mayoría de las técnicas de HRV (Heart Rate Variability).

2.14 ¿Por qué el pico R es tan importante?

El pico R posee varias ventajas:

  • es el punto más alto del ECG;
  • puede detectarse automáticamente con alta precisión;
  • aparece una vez por latido normal;
  • permite construir la serie temporal RR.

Una vez detectados todos los picos R, la señal deja de analizarse únicamente como un voltaje y comienza a estudiarse como una secuencia de tiempos entre latidos.

Ese cambio de representación es uno de los conceptos fundamentales del procesamiento moderno del ECG.

2.16 Introducción a la Variabilidad de la Frecuencia Cardíaca (HRV)

Hasta este momento el análisis del ECG se ha centrado en la forma de la señal. Sin embargo, en investigación sobre estrés rara vez se utilizan directamente las ondas P, QRS o T como entrada de un clasificador. El interés principal se desplaza hacia el tiempo que transcurre entre dos latidos consecutivos.

Ese tiempo recibe el nombre de intervalo RR porque se mide entre dos picos R.

La sucesión de todos esos intervalos constituye la Heart Rate Variability (HRV) o Variabilidad de la Frecuencia Cardíaca.

2.17 ¿Qué significa “variabilidad”?

Es frecuente pensar que un corazón sano late como un reloj.

En realidad ocurre exactamente lo contrario.

Aunque una persona tenga una frecuencia media de 60 latidos por minuto, los intervalos entre latidos no son idénticos.

Por ejemplo:

Latido 1 → Latido 2 = 1002 ms
Latido 2 → Latido 3 = 983 ms
Latido 3 → Latido 4 = 1014 ms
Latido 4 → Latido 5 = 991 ms

Todos los latidos pertenecen aproximadamente a una frecuencia de 60 lpm, pero los intervalos cambian constantemente.

Esa variación es precisamente la HRV.

2.18 ¿Por qué existe la HRV?

El corazón está regulado por el Sistema Nervioso Autónomo (SNA).

Este sistema posee dos ramas principales:

flowchart TD
A[Sistema Nervioso Autónomo]
-->B[Sistema Simpático]
A-->C[Sistema Parasimpático]

B-->D[Aumenta frecuencia cardíaca]
B-->E[Respuesta al estrés]

C-->F[Disminuye frecuencia cardíaca]
C-->G[Favorece recuperación]

Ambos sistemas actúan simultáneamente.

La frecuencia cardíaca observada en un instante es el resultado del equilibrio dinámico entre estas dos ramas.

2.19 Estrés y HRV

Cuando una persona experimenta estrés aumenta la actividad simpática y disminuye la influencia parasimpática.

Como consecuencia suele observarse:

  • incremento de la frecuencia cardíaca;
  • reducción de la variabilidad entre latidos;
  • menor capacidad de adaptación fisiológica.

Por esta razón la HRV es uno de los biomarcadores más utilizados para evaluar estrés físico y psicológico.

Es importante destacar que la respuesta depende del individuo, del contexto y de la duración del estímulo; por ello la HRV debe interpretarse junto con otras señales como EDA, EMG y respiración.

2.20 Construcción de la serie RR

Una vez detectados los picos R se calcula la diferencia temporal entre cada par consecutivo.

|--------|---------|----------|

Ahora se dispone de una serie temporal de intervalos.

Esta nueva representación constituye la entrada para la mayoría de algoritmos de HRV.

2.22 ¿Por qué estas features son útiles?

El objetivo no es obtener números por sí mismos.

Cada feature intenta responder una pregunta fisiológica distinta.

Por ejemplo:

  • ¿Qué tan estable es el ritmo cardíaco?
  • ¿El organismo responde con rapidez a pequeños cambios?
  • ¿Predomina el sistema simpático?
  • ¿Existe una buena capacidad de adaptación?

Desde esta perspectiva, una feature deja de ser únicamente una fórmula matemática y pasa a convertirse en un indicador del funcionamiento fisiológico del organismo.

2.24 Mean RR

¿Qué mide?

El Mean RR es el promedio de todos los intervalos RR de una ventana.

Si la serie RR es:

1000 995 1008 1003 997

el Mean RR representa el tiempo medio entre latidos.

Interpretación fisiológica

Un valor elevado indica que, en promedio, transcurre más tiempo entre dos latidos; un valor bajo indica que los latidos ocurren con mayor rapidez.

Es importante recordar que Mean RR no mide directamente el estrés. Describe el ritmo medio sobre el que posteriormente se interpretan otras medidas de variabilidad.

Ventajas

  • Muy fácil de calcular.
  • Robusto frente a pequeñas variaciones.
  • Base para otras métricas.

Limitaciones

No informa cuánta variabilidad existe; dos personas pueden tener el mismo Mean RR y una HRV completamente distinta.

2.25 Mean Heart Rate (Mean HR)

La frecuencia cardíaca media expresa el número promedio de latidos por minuto durante la ventana analizada.

Aunque está relacionada con Mean RR, no representan exactamente el mismo concepto.

Mayor Mean RR
        ↓
Menor frecuencia cardíaca

Menor Mean RR
        ↓
Mayor frecuencia cardíaca

Relación con el estrés

En situaciones de estrés agudo suele observarse un aumento de la frecuencia cardíaca debido a una mayor activación del sistema nervioso simpático.

Sin embargo, la frecuencia cardíaca por sí sola no permite caracterizar completamente el estado fisiológico; por ello siempre se analiza junto con la HRV.

  • SDNN bajo: ritmo más rígido y menos adaptable.

2.27 ¿Por qué SDNN es importante?

La regulación cardíaca no debe ser completamente constante.

Un organismo sano adapta continuamente el intervalo entre latidos a la respiración, la actividad física, las emociones y múltiples estímulos fisiológicos.

El SDNN resume esa capacidad de adaptación.

Por ello suele considerarse un indicador global del equilibrio del sistema nervioso autónomo.

2.29 RMSSD

El RMSSD (Root Mean Square of Successive Differences) es una de las medidas más utilizadas para evaluar la variabilidad cardíaca de corto plazo.

A diferencia del SDNN, que resume la variabilidad global, el RMSSD se concentra en los cambios entre latidos consecutivos.

Idea intuitiva

Supongamos la siguiente serie RR (ms):

1000 1012 1005 1018 1008

Primero se calcula la diferencia entre cada par consecutivo:

+12  -7  +13  -10

Posteriormente:

  1. Se elevan al cuadrado las diferencias.
  2. Se calcula su promedio.
  3. Se obtiene la raíz cuadrada.

El resultado final es el RMSSD.

flowchart LR
A[Serie RR]
-->B[Diferencias sucesivas]
-->C[Cuadrados]
-->D[Promedio]
-->E[Raíz cuadrada]
-->F[RMSSD]

¿Qué representa fisiológicamente?

El RMSSD refleja la rapidez con la que el corazón modifica el intervalo entre dos latidos consecutivos.

Está estrechamente relacionado con la actividad del sistema nervioso parasimpático, por lo que suele disminuir cuando el organismo permanece sometido a estrés agudo.

2.30 SDSD

El SDSD (Standard Deviation of Successive Differences) utiliza las mismas diferencias sucesivas de la serie RR, pero en lugar de calcular la raíz cuadrática media obtiene la desviación estándar de dichas diferencias.

Mientras el RMSSD resume la magnitud promedio de los cambios, el SDSD describe la dispersión de esos cambios.

Ambas medidas suelen comportarse de manera similar y con frecuencia aparecen juntas en los estudios de HRV.

2.35 Del dominio temporal al dominio frecuencial

Hasta este punto todas las características se obtuvieron observando la serie RR directamente. Sin embargo, existe otra pregunta de gran interés:

¿Con qué ritmo aparecen las variaciones de la frecuencia cardíaca?

Para responderla no basta con medir promedios o desviaciones. Es necesario estudiar la frecuencia con la que ocurren esas variaciones.

2.36 ¿Qué significa analizar una señal en frecuencia?

Cuando observamos una señal en el dominio temporal respondemos preguntas como:

  • ¿Cuánto dura un evento?
  • ¿Cuál es su amplitud?
  • ¿Cómo cambia con el tiempo?

En cambio, el dominio frecuencial responde preguntas diferentes:

  • ¿Qué oscilaciones contiene la señal?
  • ¿Cuáles son las oscilaciones dominantes?
  • ¿Dónde se concentra la mayor parte de la energía?

Una analogía útil es una orquesta.

Una persona puede escuchar la música completa (dominio temporal), pero también puede intentar identificar qué instrumentos participan y cuál tiene mayor protagonismo (dominio frecuencial).

2.38 El concepto de espectro

Un espectro muestra cómo se distribuye la energía de una señal entre distintas frecuencias.

En lugar de responder:

¿Cuál fue el valor de la señal en el segundo 15?

el espectro responde:

¿Qué frecuencias explican mejor el comportamiento de toda la señal?

Este cambio de perspectiva constituye uno de los pilares del procesamiento digital de señales.

2.39 La Transformada Rápida de Fourier (FFT)

La Fast Fourier Transform (FFT) es un algoritmo eficiente para calcular la Transformada de Fourier Discreta.

Su objetivo es descomponer una señal compleja en un conjunto de componentes sinusoidales de diferentes frecuencias.

Conceptualmente:

Serie RR

      ▼

      │
      ▼
Frecuencia  Potencia
0.05 Hz     ...
0.10 Hz     ...
0.20 Hz     ...
0.30 Hz     ...

La FFT no crea información nueva; reorganiza la existente para que resulte más sencillo identificar patrones periódicos.

2.40 ¿Por qué la FFT no siempre es suficiente?

La FFT supone que la señal analizada permanece aproximadamente estacionaria durante la ventana.

En señales fisiológicas esto no siempre ocurre.

Además, la estimación directa del espectro puede presentar una varianza elevada, dificultando la identificación de las bandas fisiológicas.

Por esta razón muchos trabajos utilizan una estimación espectral más estable: el método de Welch.

2.41 Método de Welch

El método de Welch divide la señal en segmentos parcialmente superpuestos.

Cada segmento se analiza por separado y posteriormente los espectros obtenidos se promedian.

flowchart LR
A[Serie RR]
-->B[Segmento 1]
A-->C[Segmento 2]
A-->D[Segmento 3]

B-->E[FFT]
C-->F[FFT]
D-->G[FFT]

E-->H[Promedio]
F-->H

Esta estrategia reduce la variabilidad de la estimación espectral y genera una densidad espectral de potencia (PSD) más robusta.

2.42 ¿Qué aprenderemos después?

Una vez obtenido el espectro, el siguiente paso consiste en calcular la energía contenida en distintas bandas fisiológicas:

  • VLF (Very Low Frequency)
  • LF (Low Frequency)
  • HF (High Frequency)
  • Relación LF/HF

Estas medidas son algunas de las features más utilizadas para estudiar el equilibrio entre la actividad simpática y parasimpática durante situaciones de estrés.

2.43 La Densidad Espectral de Potencia (PSD)

Después de aplicar la FFT o el método de Welch no se obtiene directamente una feature.

La PSD indica cómo se distribuye la potencia (energía) de la variabilidad cardíaca en función de la frecuencia.

2.44 ¿Qué significa “potencia”?

En procesamiento de señales, la potencia representa la contribución energética de una determinada frecuencia.

No debe confundirse con la potencia eléctrica de un circuito.

En HRV, una frecuencia con mayor potencia indica que las variaciones del ritmo cardíaco contienen una oscilación importante en ese rango de frecuencias.

2.45 Bandas fisiológicas de frecuencia

Una vez obtenida la PSD, el espectro se divide en bandas fisiológicas.

Banda Intervalo aproximado Interpretación general

HF 0.15 – 0.40 Hz Actividad parasimpática y respiración

Estas bandas no fueron elegidas al azar. Décadas de investigación mostraron que diferentes mecanismos fisiológicos producen oscilaciones predominantes en distintos rangos de frecuencia.

2.46 Banda VLF (Very Low Frequency)

La banda VLF contiene las oscilaciones más lentas de la HRV.

Su interpretación fisiológica continúa siendo objeto de investigación, aunque se ha relacionado con procesos como:

  • regulación hormonal;
  • termorregulación;
  • mecanismos inflamatorios;
  • ritmos biológicos de larga duración.

En ventanas cortas, como las utilizadas en WESAD, esta banda suele interpretarse con cautela porque la resolución espectral es limitada.

2.47 Banda LF (Low Frequency)

La banda LF comprende aproximadamente el rango entre 0.04 y 0.15 Hz.

Tradicionalmente se consideró un indicador de actividad simpática. Sin embargo, la evidencia actual muestra que refleja una interacción entre mecanismos simpáticos y parasimpáticos, además del reflejo barorreceptor.

Por ello, interpretar LF como un marcador exclusivo del sistema simpático constituye una simplificación excesiva.

2.48 Banda HF (High Frequency)

La banda HF se encuentra entre 0.15 y 0.40 Hz.

Está estrechamente relacionada con la respiración.

Cuando inspiramos y espiramos, la frecuencia cardíaca cambia ligeramente. Este fenómeno recibe el nombre de arritmia sinusal respiratoria.

Como consecuencia, la potencia en HF suele asociarse con la actividad del sistema nervioso parasimpático.

Por ello, la relación LF/HF debe analizarse junto con el resto de features y nunca de forma aislada.

2.51 Interpretación detallada de la potencia LF

La potencia LF (Low Frequency Power) representa la energía contenida en la banda de 0.04 a 0.15 Hz de la densidad espectral de potencia (PSD).

¿Qué significa intuitivamente?

Algunas variaciones son muy lentas, otras muy rápidas y otras tienen un ritmo intermedio. La banda LF mide precisamente la intensidad de esas oscilaciones intermedias.

No mide directamente el número de latidos, sino la energía asociada a un determinado rango de frecuencias.

Fundamento fisiológico

  • actividad simpática;
  • actividad parasimpática;
  • reflejo barorreceptor;
  • regulación cardiovascular.

2.52 Potencia HF

La potencia HF cuantifica la energía presente entre 0.15 y 0.40 Hz.

Relación con la respiración

Durante la inspiración la frecuencia cardíaca aumenta ligeramente.

Durante la espiración disminuye.

Como consecuencia, una parte importante de la energía del espectro aparece concentrada en la banda HF.

2.53 Potencias normalizadas

En numerosos estudios las potencias LF y HF también se expresan en forma normalizada.

El objetivo es reducir la influencia de la potencia total y facilitar la comparación entre individuos.

De esta manera se obtienen:

  • LF normalizada.
  • HF normalizada.

Estas medidas no sustituyen las potencias originales; constituyen otra forma de representar la distribución relativa de la energía espectral.

2.55 Errores frecuentes al interpretar LF y HF

Uno de los errores más comunes consiste en asumir que:

  • LF = simpático.
  • HF = parasimpático.

Aunque esta interpretación fue ampliamente difundida durante años, actualmente se reconoce que resulta demasiado simplificada.

Otro error frecuente consiste en comparar directamente potencias obtenidas con ventanas de duración diferente.

La longitud de la ventana modifica la resolución espectral y, por tanto, puede afectar las features obtenidas.

  • utilizar ventanas consistentes durante todo el experimento;
  • documentar el método espectral empleado (FFT o Welch);
  • indicar claramente la longitud de la ventana y el solapamiento;
  • interpretar LF y HF junto con las métricas temporales y las demás señales fisiológicas.

La combinación de ECG, EDA, EMG, respiración, temperatura y acelerometría suele ofrecer una descripción mucho más robusta del estado fisiológico que el uso aislado de una única señal.

2.57 ¿Por qué el dominio no lineal?

Hasta ahora se ha asumido que el comportamiento del corazón puede describirse mediante promedios, desviaciones estándar o análisis espectrales. Sin embargo, el sistema cardiovascular es un sistema biológico complejo donde intervienen múltiples mecanismos de retroalimentación.

La regulación cardíaca depende, entre otros factores, de:

  • Sistema nervioso simpático.
  • Sistema nervioso parasimpático.
  • Respiración.
  • Presión arterial.
  • Regulación hormonal.
  • Actividad física.
  • Estado emocional.
  • Ritmos circadianos.

Estos mecanismos interactúan de manera simultánea y no siempre producen respuestas lineales.

2.58 ¿Qué significa “no lineal”?

Un sistema lineal responde de forma proporcional a un estímulo.

En cambio, un sistema no lineal puede producir respuestas muy diferentes ante pequeñas variaciones de las condiciones iniciales.

El corazón pertenece a esta segunda categoría.

Dos personas pueden tener:

  • la misma frecuencia cardíaca,
  • el mismo SDNN,
  • el mismo RMSSD,

y aun así presentar patrones completamente distintos cuando se analiza la estructura de sus intervalos RR.

Por esta razón surgieron las técnicas de análisis no lineal.

2.59 Del ritmo al patrón

Hasta ahora hemos preguntado:

  • ¿Cuál es el promedio?
  • ¿Cuál es la desviación?
  • ¿Dónde está la energía?

El análisis no lineal formula preguntas distintas:

  • ¿Existe un patrón repetitivo?
  • ¿Qué tan complejo es el sistema?
  • ¿Cuánta información nueva aparece con cada latido?
  • ¿Es un comportamiento caótico o altamente regular?

Estas preguntas permiten describir propiedades que no aparecen en los análisis tradicionales.

2.64 ¿Qué significa que una señal sea compleja?

Hasta ahora hemos descrito la serie RR mediante promedios, desviaciones estándar y espectros de frecuencia. Sin embargo, estas medidas no responden a una pregunta fundamental:

¿Qué tan predecible o impredecible es el comportamiento del corazón?

La respuesta conduce al concepto de complejidad.

Una señal perfectamente regular es fácil de predecir. Por el contrario, una señal totalmente aleatoria también resulta poco informativa porque no presenta organización.

Las señales fisiológicas sanas suelen encontrarse entre ambos extremos: poseen orden, pero también variabilidad.

2.65 Entropía en procesamiento de señales

En términos generales, la entropía cuantifica el grado de incertidumbre o irregularidad de una serie temporal.

No debe confundirse con la entropía de la termodinámica, aunque ambas comparten la idea de medir el desorden de un sistema.

En HRV, una entropía elevada suele indicar que la serie RR presenta una organización compleja, mientras que una entropía muy baja refleja un comportamiento excesivamente regular.

La Approximate Entropy (ApEn) fue propuesta por Steven Pincus para cuantificar la regularidad de una serie temporal.

ApEn intenta responder:

¿Con qué frecuencia un patrón observado vuelve a repetirse?

Si los patrones son muy repetitivos, la entropía disminuye.

Si los patrones rara vez se repiten, la entropía aumenta.

2.67 ¿Cómo calcula ApEn esta información?

De forma simplificada, el algoritmo sigue estos pasos:

  1. Construye pequeños vectores a partir de la serie RR.
  2. Compara cada vector con los demás.
  3. Cuenta cuántos son similares dentro de una tolerancia.
  4. Amplía el tamaño de los vectores.
  5. Repite el proceso.
  6. Calcula cuánto disminuye la probabilidad de encontrar patrones similares.

Cuanto mayor sea esa disminución, mayor será la Approximate Entropy.

2.68 Limitaciones de ApEn

Aunque ApEn revolucionó el análisis no lineal de señales fisiológicas, presenta varias limitaciones:

  • depende del tamaño de la muestra;
  • puede incluir autocomparaciones;
  • resulta sensible a la selección de parámetros;
  • puede sobreestimar la regularidad en series cortas.

Estas limitaciones motivaron el desarrollo de una medida mejorada: la Sample Entropy.

2.69 Sample Entropy (SampEn)

La Sample Entropy (SampEn) conserva la filosofía de ApEn, pero elimina las autocomparaciones y mejora la estabilidad estadística.

Por ello es una de las métricas más utilizadas en estudios modernos de HRV.

Las entropías no miden si el corazón late rápido o lento.

Tampoco describen la potencia de una banda de frecuencia.

2.71 ¿Por qué medir la complejidad en varias escalas?

La Approximate Entropy (ApEn) y la Sample Entropy (SampEn) describen la irregularidad de una serie temporal considerando una única escala temporal. Sin embargo, muchos procesos fisiológicos no actúan en un solo nivel.

El corazón está regulado simultáneamente por mecanismos rápidos (como la respiración) y por mecanismos lentos (como la regulación hormonal o la presión arterial). Por ello, resulta útil estudiar la complejidad en diferentes escalas de observación.

La Multiscale Entropy (MSE), propuesta por Costa, Goldberger y Peng, amplía la idea de la Sample Entropy.

2.73 Interpretación de la MSE

En términos generales:

  • Una señal fisiológica saludable suele mantener niveles de complejidad relativamente altos en varias escalas.
  • Una pérdida de complejidad puede asociarse con envejecimiento, enfermedad o una menor capacidad de adaptación.

Es importante destacar que la interpretación depende del contexto clínico y experimental.

2.74 Permutation Entropy

La Permutation Entropy (PE) no analiza únicamente la amplitud de los datos, sino el orden relativo en que aparecen.

Considere dos secuencias:

2 4 8

y

10 20 40

Aunque los valores son distintos, ambas presentan el mismo patrón de crecimiento.

La Permutation Entropy estudia precisamente estos patrones ordinales.

Esto la hace especialmente robusta frente a cambios de escala y pequeñas perturbaciones.

2.75 Ventajas de la Permutation Entropy

Entre sus principales ventajas destacan:

  • bajo costo computacional;
  • robustez frente al ruido moderado;
  • facilidad de interpretación;
  • buen desempeño en señales fisiológicas.

Por estas razones aparece con frecuencia en estudios recientes sobre estrés, epilepsia y análisis cardiovascular.

2.76 Introducción al análisis fractal

Las señales biológicas presentan propiedades que se repiten parcialmente en diferentes escalas.

Este comportamiento recibe el nombre de autosimilitud y constituye uno de los fundamentos del análisis fractal.

La pregunta principal cambia nuevamente:

¿Cómo evolucionan las fluctuaciones cuando cambia la escala de observación?

Responder esta pregunta permite caracterizar la organización de largo alcance de la serie RR.

2.77 Detrended Fluctuation Analysis (DFA)

El Detrended Fluctuation Analysis (DFA) es una de las herramientas más utilizadas para estudiar correlaciones de largo alcance en series temporales no estacionarias.

De forma resumida, el procedimiento consiste en:

  1. Integrar la serie.
  2. Dividirla en ventanas.
  3. Ajustar una tendencia local en cada ventana.
  4. Eliminar dicha tendencia.
  5. Medir las fluctuaciones restantes.
  6. Analizar cómo cambian al variar el tamaño de la ventana.
flowchart TD
A[Serie RR]
-->B[Integración]
-->C[Ventanas]
-->D[Eliminación de tendencia]
-->E[Fluctuaciones]
-->F[Exponentes DFA]

Los exponentes más habituales son α1 (corto plazo) y α2 (largo plazo).

2.78 Exponente de Hurst

Otra medida ampliamente utilizada es el exponente de Hurst (H).

Este parámetro describe el grado de persistencia de una serie temporal.

De forma simplificada:

Valor de H Interpretación
H ≈ 0.5 Comportamiento similar al azar
H > 0.5 Persistencia
H < 0.5 Antipersistencia

El exponente de Hurst ayuda a comprender si las tendencias observadas tienden a mantenerse o a invertirse con el tiempo.

2.80 Introducción al Recurrence Quantification Analysis (RQA)

Las técnicas estudiadas hasta este punto describen el comportamiento del corazón desde diferentes perspectivas: temporal, frecuencial, geométrica y entrópica.

Sin embargo, aún queda una pregunta importante:

¿Cómo evoluciona la dinámica del sistema cuando un estado fisiológico vuelve a aparecer?

Responder esta pregunta es el objetivo del Recurrence Quantification Analysis (RQA).

El RQA es una familia de técnicas desarrolladas para estudiar sistemas dinámicos complejos, permitiendo identificar cuándo un sistema regresa a estados similares a los observados anteriormente.

2.81 ¿Qué es una recurrencia?

Imagine que una persona camina por una ciudad.

Aunque nunca siga exactamente la misma ruta, puede regresar muchas veces a lugares muy parecidos.

Con el corazón ocurre algo similar.

Durante la regulación cardiovascular aparecen continuamente estados fisiológicos que se parecen entre sí.

El análisis de recurrencia estudia precisamente estos “regresos” del sistema.

Valores elevados indican que la dinámica presenta numerosos estados repetidos.

Valores bajos sugieren una mayor dispersión de los estados.

No debe confundirse con Sample Entropy o Approximate Entropy.

La RQA Entropy describe la distribución de las longitudes de las líneas diagonales.

Si existen diagonales muy variadas, la entropía aumenta.

Si todas presentan tamaños similares, la entropía disminuye.

Por tanto, esta medida caracteriza la diversidad estructural del sistema dinámico.

2.89 Laminarity (LAM)

Las líneas verticales del diagrama representan periodos durante los cuales el sistema permanece en estados muy parecidos.

La métrica LAM cuantifica precisamente esta propiedad.

Valores elevados indican que el sistema pasa más tiempo evolucionando lentamente.

2.90 Trapping Time (TT)

El Trapping Time (TT) mide cuánto tiempo permanece el sistema atrapado en estados similares antes de cambiar hacia otra región del espacio de fases.

Esta característica complementa la información proporcionada por LAM.

2.91 Aplicación del RQA al ECG

  • media,
  • SDNN,
  • RMSSD,
  • bandas espectrales,
  • entropías tradicionales.

Por ello, numerosos trabajos combinan RQA con otras familias de características para mejorar la detección automática del estrés.

3.1 ¿Qué es la Actividad Electrodérmica (EDA)?

La Actividad Electrodérmica (Electrodermal Activity, EDA) es una señal fisiológica que describe las variaciones en la conductancia eléctrica de la piel.

A diferencia del ECG, que refleja la actividad eléctrica del corazón, la EDA está relacionada con la actividad de las glándulas sudoríparas ecrinas, controladas principalmente por el sistema nervioso simpático.

Por ello, la EDA es una de las señales más utilizadas para estudiar:

  • estrés;
  • carga cognitiva;
  • atención;
  • activación emocional;
  • ansiedad.

3.2 Fundamento fisiológico

Cuando una persona experimenta una emoción intensa, resuelve un problema complejo o se enfrenta a una situación estresante, aumenta la actividad simpática.

Este incremento estimula las glándulas sudoríparas, especialmente en las palmas de las manos y los dedos.

Aunque el sudor no siempre sea visible, modifica la conductancia eléctrica de la piel.

flowchart LR
A[Estímulo]
-->B[Sistema nervioso simpático]
-->C[Glándulas sudoríparas]
-->D[Cambio en conductancia]
-->E[Señal EDA]

3.3 Conductancia y resistencia

La piel puede entenderse como un material cuya capacidad para conducir electricidad cambia con la cantidad de humedad presente.

Cuando aumenta el sudor:

  • la resistencia disminuye;
  • la conductancia aumenta.

La EDA suele expresarse en microsiemens (µS).

3.4 Componentes de la EDA

La señal EDA está formada por dos componentes principales.

Componente tónico (SCL)

El Skin Conductance Level (SCL) representa el nivel basal de conductancia.

Varía lentamente y refleja el estado general de activación fisiológica.

Componente fásico (SCR)

La Skin Conductance Response (SCR) corresponde a respuestas rápidas provocadas por eventos específicos.

Estas respuestas aparecen como pequeños picos superpuestos al nivel basal.

3.5 ¿Por qué separar SCL y SCR?

Si analizáramos únicamente la señal completa sería difícil distinguir entre:

  • cambios lentos debidos al estado fisiológico general;
  • respuestas rápidas asociadas a estímulos concretos.

Por ello, gran parte del preprocesamiento consiste en separar ambos componentes.

3.6 La EDA en WESAD

En el conjunto de datos WESAD, la EDA fue registrada mediante el dispositivo Empatica E4.

La frecuencia de muestreo es menor que la utilizada para el ECG, pero resulta suficiente para capturar tanto el componente tónico como las respuestas fásicas.

Esto convierte a la EDA en una de las señales más informativas para la detección automática del estrés.

3.9 Anatomía de las glándulas sudoríparas ecrinas

Las glándulas ecrinas son las principales responsables de la señal EDA. Están distribuidas por casi toda la superficie corporal, aunque alcanzan su mayor densidad en:

  • Palmas de las manos.
  • Dedos.
  • Plantas de los pies.

Estas glándulas están inervadas por el sistema nervioso simpático, por lo que reaccionan rápidamente ante estímulos emocionales o cognitivos.

flowchart LR

3.10 ¿Cómo se adquiere la señal EDA?

La EDA se obtiene aplicando una corriente eléctrica muy pequeña entre dos electrodos en contacto con la piel.

El dispositivo mide cómo cambia la conductancia conforme varía la cantidad de sudor presente en la epidermis.

En WESAD, esta medición se realiza mediante el Empatica E4, que registra la EDA en la muñeca.

3.11 Frecuencia de muestreo en WESAD

La señal EDA del Empatica E4 se registra a 4 Hz, es decir, cuatro muestras por segundo.

Aunque esta frecuencia es muy inferior a la utilizada para ECG, resulta suficiente porque la EDA evoluciona lentamente y sus cambios relevantes ocurren en escalas de varios segundos.

3.12 Principales fuentes de ruido

Antes de extraer características es necesario identificar posibles artefactos.

Las fuentes más comunes son:

  • movimientos bruscos de la muñeca;
  • pérdida temporal de contacto entre el sensor y la piel;
  • cambios de temperatura;
  • desplazamiento de los electrodos;
  • interferencias eléctricas.

Estos efectos pueden alterar la amplitud y la forma de la señal.

Debido a la naturaleza lenta de la EDA, suele emplearse un filtro paso bajo para eliminar componentes de alta frecuencia asociados principalmente al ruido.

Es importante documentar siempre el tipo de filtro, el orden y los parámetros utilizados para garantizar la reproducibilidad.

La señal registrada es una combinación de un componente lento (SCL) y respuestas rápidas (SCR).

Existen diferentes estrategias para separar ambos componentes:

  • filtrado clásico;
  • deconvolución;
  • modelos convexos como cvxEDA;
  • algoritmos implementados en bibliotecas como NeuroKit2 y BioSPPy.

Cada método presenta ventajas y limitaciones según el nivel de ruido y la calidad de la adquisición.

3.16 Introducción a cvxEDA

El método cvxEDA modela la señal como la suma de varios componentes:

  • componente tónico;
  • componente fásico;
  • ruido residual.

Mediante optimización convexa estima simultáneamente estos elementos, proporcionando una descomposición más robusta que los enfoques basados únicamente en filtros.

Esta metodología es ampliamente utilizada en investigaciones recientes sobre estrés y emoción.

3.18 El componente tónico (SCL)

El Skin Conductance Level (SCL) representa el nivel basal de conductancia de la piel. A diferencia del componente fásico, el SCL evoluciona lentamente y refleja el estado general de activación del organismo.

  • carga cognitiva,
  • estrés sostenido,
  • temperatura ambiental,

El SCL no responde a un estímulo puntual, sino al contexto fisiológico global.

Por ejemplo:

  • un estudiante relajado suele presentar un SCL relativamente estable;
  • durante una tarea mental exigente el SCL puede aumentar;
  • bajo estrés prolongado el nivel basal puede mantenerse elevado.

3.21 Media del SCL

¿Qué mide?

Interpretación

  • Valores altos pueden asociarse con mayor activación simpática.

3.22 Mediana del SCL

La mediana describe el valor central del SCL.

Es menos sensible a valores atípicos que la media y resulta útil cuando existen artefactos o respuestas aisladas de gran amplitud.

3.23 Desviación estándar

La desviación estándar cuantifica cuánto fluctúa el SCL alrededor de su media.

  • Valores pequeños indican un nivel tónico estable.
  • Valores grandes reflejan una mayor variabilidad durante la ventana analizada.

3.24 Valor mínimo y máximo

Estas características delimitan el rango observado del SCL.

  • Mínimo: menor nivel de conductancia registrado.
  • Máximo: mayor nivel observado.

Aunque por sí solas ofrecen poca información, complementan otras medidas descriptivas.

3.25 Rango

El rango corresponde a:

Rango = Máximo − Mínimo

Un rango elevado puede indicar cambios importantes en el estado fisiológico o la presencia de respuestas fásicas parcialmente superpuestas.

3.40 Mean SCR Amplitude

¿Qué mide?

La Mean SCR Amplitude es la amplitud promedio de todas las respuestas SCR presentes en una ventana de análisis.

Fundamento fisiológico

La amplitud representa la intensidad de la respuesta simpática ante uno o varios estímulos. En términos generales, respuestas de mayor amplitud indican una mayor activación de las glándulas sudoríparas ecrinas.

Cálculo

Si en una ventana existen las amplitudes:

0.18  0.24  0.31  0.27 µS

La media es:

(0.18 + 0.24 + 0.31 + 0.27) / 4 = 0.25 µS

Interpretación

  • Valores bajos: respuestas discretas o baja reactividad.
  • Valores altos: mayor intensidad promedio de activación simpática.

3.41 Max SCR Amplitude

¿Qué mide?

Corresponde a la amplitud máxima registrada en una ventana.

Esta feature identifica la respuesta más intensa observada.

Ventajas

  • Fácil de interpretar.
  • Útil cuando interesa detectar eventos fisiológicos intensos.

Limitaciones

Este enfoque permite identificar patrones lentos y rápidos asociados con la activación del sistema nervioso simpático.

3.49 Densidad Espectral de Potencia (PSD)

La Power Spectral Density (PSD) describe cómo se distribuye la potencia de la señal según la frecuencia.

A diferencia del ECG, la mayor parte de la energía de la EDA se concentra en frecuencias muy bajas debido a la naturaleza lenta de la respuesta electrodérmica.

La PSD sirve como punto de partida para extraer variables relacionadas con:

  • potencia total;
  • potencia por bandas;
  • frecuencia dominante;
  • frecuencia del pico principal.

3.50 Potencia total

La potencia total resume la energía global contenida en el espectro de la EDA.

Interpretación fisiológica

Un incremento de la potencia total puede indicar una mayor variabilidad de la actividad electrodérmica durante la ventana analizada.

Sin embargo, esta medida debe interpretarse junto con las características del SCL y del SCR, ya que la potencia total no distingue el origen fisiológico de las oscilaciones.

3.52 Entropías aplicadas a la EDA

Las medidas de entropía también pueden calcularse sobre la EDA para cuantificar la complejidad de la señal.

Las más utilizadas son:

  • Approximate Entropy (ApEn).
  • Sample Entropy (SampEn).
  • Permutation Entropy.

Estas métricas permiten describir el grado de regularidad de la actividad electrodérmica, independientemente de su amplitud.

3.53 Approximate Entropy (ApEn)

La Approximate Entropy mide la probabilidad de que patrones similares continúen siendo similares cuando aumenta la longitud de la secuencia comparada.

En EDA:

  • valores bajos indican una señal muy regular;
  • valores altos reflejan una mayor complejidad temporal.

La interpretación depende del protocolo experimental y del nivel de ruido presente.

3.54 Sample Entropy (SampEn)

La Sample Entropy mejora la estabilidad de ApEn al eliminar las autocomparaciones.

Es una de las métricas no lineales más utilizadas para caracterizar la dinámica de la EDA, especialmente en estudios de estrés y carga cognitiva.

3.55 Permutation Entropy

La Permutation Entropy analiza el orden relativo de las muestras en lugar de su valor absoluto.

Esto la hace robusta frente a cambios de escala y pequeñas perturbaciones.

En la EDA resulta útil cuando se desea estudiar la organización temporal de la señal sin que las diferencias de amplitud dominen el análisis.

3.56 Detrended Fluctuation Analysis (DFA)

El Detrended Fluctuation Analysis permite estudiar correlaciones de largo alcance incluso cuando la señal no es completamente estacionaria.

En la EDA puede emplearse para analizar cómo evolucionan las fluctuaciones de la conductancia a diferentes escalas temporales.

Las características extraídas poseen escalas muy diferentes.

Por ejemplo:

  • el SCL se expresa en microsiemens;
  • la pendiente puede expresarse en µS/s;
  • la entropía no tiene unidades;
  • la potencia espectral depende del método de cálculo.

Antes de entrenar un modelo predictivo es recomendable aplicar un procedimiento de normalización consistente.

Los métodos más utilizados incluyen:

  • estandarización (z-score);
  • escalado Min-Max;
  • escalado robusto basado en la mediana.

  • análisis de correlación;
  • información mutua;
  • Recursive Feature Elimination (RFE);
  • importancia basada en Random Forest;
  • regularización mediante LASSO.

La selección adecuada mejora la interpretabilidad del modelo y reduce el riesgo de sobreajuste.

  5. Evitar utilizar información del conjunto de prueba durante el entrenamiento (data leakage).

Estas recomendaciones son especialmente importantes cuando se comparan diferentes modelos de aprendizaje automático.

4.1 ¿Qué es la Electromiografía (EMG)?

La Electromiografía (Electromyography, EMG) es la técnica utilizada para registrar la actividad eléctrica producida por los músculos durante la contracción y la relajación.

Cada vez que el sistema nervioso envía una orden a un músculo, las fibras musculares generan pequeños potenciales eléctricos. La suma de la actividad de miles de fibras produce la señal EMG que registran los electrodos.

A diferencia del ECG, que representa la actividad del corazón, el EMG describe la actividad del sistema neuromuscular.

4.2 Tipos de electromiografía

Existen dos grandes modalidades.

Electromiografía invasiva

Se realiza mediante agujas insertadas en el músculo.

Características:

  • Alta resolución espacial.
  • Uso clínico.
  • Procedimiento invasivo.

Electromiografía de superficie (sEMG)

Utiliza electrodos adheridos sobre la piel.

Características:

  • No invasiva.
  • Fácil adquisición.
  • Muy utilizada en investigación y en interfaces hombre-máquina.

En WESAD se utiliza electromiografía de superficie (sEMG).

4.3 Fundamento fisiológico

Cuando una neurona motora descarga un impulso eléctrico, todas las fibras pertenecientes a su unidad motora se activan casi simultáneamente.

flowchart LR
A[Corteza motora]
-->B[Neurona motora]
-->C[Unidad motora]
-->D[Fibras musculares]
-->E[Señal EMG]

La señal registrada representa la suma de la actividad de muchas unidades motoras activas.

4.4 ¿Qué mide realmente la señal EMG?

El EMG no mide directamente la fuerza muscular.

Lo que registra es la actividad eléctrica asociada a la activación del músculo.

Aunque exista una relación entre activación y fuerza, esta depende de múltiples factores:

  • tipo de músculo;
  • velocidad de contracción;
  • fatiga;
  • postura;
  • características individuales.

Por esta razón, una mayor amplitud del EMG no implica necesariamente una mayor fuerza.

4.5 Aplicaciones del EMG

La electromiografía tiene aplicaciones en numerosos campos.

Entre ellas destacan:

  • rehabilitación;
  • biomecánica;
  • prótesis inteligentes;
  • interfaces cerebro-computador;
  • robótica;
  • ergonomía;
  • detección de fatiga;
  • análisis del estrés.

En estudios de estrés, el aumento de la tensión muscular suele reflejarse en un incremento de la actividad EMG.

Su incorporación permite caracterizar la tensión muscular asociada a diferentes estados emocionales.

4.10 Anatomía de la unidad motora

La unidad motora está formada por una neurona motora y todas las fibras musculares que inerva. Cuando la neurona genera un potencial de acción, todas las fibras de esa unidad se contraen de manera prácticamente simultánea.

flowchart LR
A[Neurona motora]
-->B[Axón]
-->C[Placa neuromuscular]
-->D[Fibras musculares]
-->E[Potencial de acción muscular]

La señal EMG registrada en superficie es la suma de la actividad de numerosas unidades motoras activas.

4.11 Generación de la señal EMG

El proceso fisiológico puede resumirse así:

  1. El cerebro envía una orden motora.
  2. La neurona motora transmite el impulso.
  3. Las fibras musculares se despolarizan.
  4. Se produce la contracción.
  5. Los electrodos registran la actividad eléctrica.

La amplitud y la forma del EMG dependen del número de unidades motoras activadas y de su nivel de sincronización.

4.12 Adquisición del EMG en WESAD

En WESAD el EMG fue registrado con RespiBAN sobre la región torácica.

Aspectos importantes:

  • Frecuencia de muestreo: 700 Hz.
  • Registro sincronizado con ECG, EDA, respiración y temperatura.
  • Señal de alta resolución temporal.

Una frecuencia de muestreo elevada permite conservar componentes rápidas de la actividad muscular.

4.13 Principales fuentes de ruido

La señal EMG suele contaminarse por diversas interferencias:

  • ruido térmico del sistema electrónico;
  • movimiento de los electrodos;
  • interferencia de la red eléctrica (50/60 Hz);
  • actividad de músculos vecinos (cross-talk);
  • artefactos por movimiento.

La identificación de estas fuentes es esencial antes de extraer características.

4.14 Filtrado paso banda

El preprocesamiento comienza normalmente con un filtro paso banda para eliminar componentes de muy baja y muy alta frecuencia.

flowchart LR
A[EMG cruda]
-->B[Filtro paso banda]
-->C[EMG filtrada]

El rango exacto depende del protocolo experimental, pero el objetivo es conservar la banda útil de la actividad muscular y reducir el ruido.

4.15 Filtro Notch

La red eléctrica introduce una interferencia periódica cercana a 50 Hz o 60 Hz, según el país.

Para reducirla se emplea un filtro notch, diseñado para atenuar una frecuencia muy específica sin afectar de forma importante el resto del espectro.

4.16 Rectificación

El EMG oscila alrededor de cero con valores positivos y negativos.

Para cuantificar su intensidad suele aplicarse una rectificación de onda completa, consistente en calcular el valor absoluto de cada muestra.

EMG original:   -0.3  0.4 -0.2  0.5
Rectificada:     0.3  0.4  0.2  0.5

La rectificación facilita el cálculo de variables relacionadas con la amplitud.

4.17 Envolvente de la señal

Tras la rectificación es habitual calcular una envolvente, que representa la evolución suavizada de la actividad muscular.

Los métodos más comunes son:

  • filtro paso bajo sobre la señal rectificada;
  • RMS (Root Mean Square);
  • media móvil.

La envolvente permite identificar con claridad los periodos de activación y relajación.

4.20 Mean Absolute Value (MAV)

¿Qué mide?

El Mean Absolute Value (MAV) representa el valor absoluto medio de la amplitud de la señal EMG dentro de una ventana temporal.

Es una de las medidas más utilizadas para estimar el nivel de activación muscular.

Fundamento fisiológico

Cuando aumenta el número de unidades motoras activas o su frecuencia de descarga, la amplitud promedio de la señal también suele incrementarse. Por ello, el MAV se considera un indicador indirecto del esfuerzo muscular.

Expresión matemática

[ MAV=_{i=1}^{N}|x_i| ]

donde:

  • (x_i): muestra de la señal EMG.
  • (N): número de muestras de la ventana.

Ejemplo

Supóngase la siguiente ventana rectificada:

0.20   0.35   0.40   0.25   0.30

Entonces:

MAV = (0.20 + 0.35 + 0.40 + 0.25 + 0.30) / 5
MAV = 0.30

Interpretación

  • Valores bajos: escasa activación muscular.
  • Valores altos: mayor reclutamiento de unidades motoras.

Ventajas

  • Muy sencilla de calcular.
  • Robusta en aplicaciones en tiempo real.
  • Ampliamente utilizada en reconocimiento de patrones EMG.

Limitaciones

No proporciona información sobre el contenido frecuencial de la señal.

4.24 Variance (VAR)

¿Qué mide?

La Variance (VAR) cuantifica la dispersión de la amplitud de la señal EMG respecto a su valor medio.

Fundamento fisiológico

Cuando aumenta el reclutamiento de unidades motoras o la intensidad de la contracción, la variabilidad de la señal suele incrementarse.

Fórmula

[ VAR=_{i=1}{N}(x_i-{x})2 ]

Interpretación

  • VAR baja: actividad muscular estable.
  • VAR alta: mayor variabilidad y activación muscular.

Ventajas

  • Resume la variabilidad de la señal.
  • Fácil implementación.

Limitaciones

  • Sensible a valores atípicos.

4.25 Simple Square Integral (SSI)

El Simple Square Integral (SSI) estima la energía acumulada de la señal.

Fórmula

[ SSI=_{i=1}{N}x_i2 ]

Cuanto mayor sea el SSI, mayor será la energía contenida en la ventana analizada.

Aplicaciones

  • Cuantificación del esfuerzo.
  • Estudios de fatiga muscular.
  • Reconocimiento de gestos.

La Waveform Length (WL) representa la longitud total recorrida por la señal.

Fórmula

Interpretación

  • Valores altos: señal más compleja o intensa.

La Zero Crossing (ZC) cuenta cuántas veces la señal cruza el valor cero.

Una mayor cantidad de cruces suele asociarse con señales que contienen componentes de mayor frecuencia.

4.34 Densidad Espectral de Potencia (PSD)

La Power Spectral Density (PSD) representa cómo se distribuye la potencia de la señal en función de la frecuencia.

En la práctica, la PSD suele estimarse mediante el método de Welch, ya que reduce la varianza de la estimación al promediar varios segmentos parcialmente solapados.

Aplicaciones

  • cuantificar energía por bandas;
  • calcular frecuencias características;
  • estudiar fatiga muscular;
  • comparar condiciones experimentales.

4.35 Potencia espectral total

La potencia espectral total corresponde a la energía acumulada en todo el espectro de la señal.

Matemáticamente equivale al área bajo la curva de la PSD.

Interpretación

  • Valores altos: mayor actividad eléctrica muscular.
  • Valores bajos: menor intensidad global de activación.

Debe interpretarse junto con otras variables, ya que una misma potencia puede distribuirse de formas diferentes en el espectro.

4.36 Mean Frequency (MNF)

¿Qué mide?

La Mean Frequency (MNF) representa el promedio ponderado de las frecuencias presentes en el espectro.

En términos intuitivos, resume el “centro de gravedad” de la distribución espectral.

Interpretación fisiológica

Durante procesos de fatiga muscular suele observarse un desplazamiento del espectro hacia frecuencias más bajas, lo que puede reflejarse en una disminución del MNF.

La Median Frequency (MDF) divide el espectro en dos regiones con la misma potencia.

4.38 Frecuencia pico (Peak Frequency)

La Peak Frequency es la frecuencia en la que la PSD alcanza su valor máximo.

Esta característica identifica la componente dominante de la señal EMG.

Aunque es sencilla de calcular, puede verse afectada por ruido o por la presencia de varios picos de potencia similares.

4.42 Approximate Entropy (ApEn)

¿Qué mide?

La Approximate Entropy (ApEn) cuantifica el grado de regularidad de una serie temporal.

  • Valores bajos indican una señal más predecible.
  • Valores altos reflejan mayor irregularidad.

Fundamento

ApEn compara patrones de longitud m y evalúa la probabilidad de que continúen siendo similares al incorporar una muestra adicional.

Aplicaciones

  • Fatiga muscular.
  • Control motor.
  • Clasificación de estados fisiológicos.

4.43 Sample Entropy (SampEn)

La Sample Entropy (SampEn) es una evolución de ApEn que elimina las autocomparaciones, reduciendo el sesgo de la estimación.

Ventajas

  • Mayor estabilidad.
  • Mejor comportamiento con registros cortos.
  • Muy utilizada en estudios de bioseñales.

4.44 Permutation Entropy

La Permutation Entropy analiza el orden relativo de las muestras, en lugar de su amplitud.

Esto la hace robusta frente a cambios de escala y pequeñas perturbaciones.

Interpretación

  • Baja entropía: organización elevada.
  • Alta entropía: comportamiento más complejo.

4.45 Spectral Entropy

La Spectral Entropy se calcula a partir de la densidad espectral de potencia (PSD).

Describe cuán distribuida está la energía entre las distintas frecuencias.

  • Energía concentrada → entropía baja.
  • Energía distribuida → entropía alta.

4.46 Dimensión fractal

La Dimensión Fractal estima la complejidad geométrica de la señal.

Los algoritmos más empleados en EMG son:

  • Higuchi Fractal Dimension (HFD).
  • Katz Fractal Dimension (KFD).

Una dimensión fractal elevada suele indicar una señal con mayor complejidad estructural.

4.47 Detrended Fluctuation Analysis (DFA)

El DFA evalúa correlaciones de largo alcance en señales no estacionarias.

En EMG permite estudiar cómo evolucionan las fluctuaciones a distintas escalas temporales.

Esta medida ha sido utilizada para analizar:

  • control neuromuscular;
  • fatiga;
  • alteraciones motoras.

4.48 Exponente de Hurst

El Hurst Exponent (H) describe la persistencia temporal de una serie.

  • H ≈ 0.5: comportamiento aleatorio.
  • H > 0.5: persistencia.
  • H < 0.5: antipersistencia.

En EMG puede aportar información sobre la organización del control muscular.

4.49 Recurrence Quantification Analysis (RQA)

El RQA analiza la dinámica del sistema mediante diagramas de recurrencia.

Las variables más comunes incluyen:

  • Recurrence Rate (RR).
  • Determinism (DET).
  • Laminarity (LAM).
  • Entropy (ENTR).

Estas medidas permiten caracterizar cambios sutiles en la dinámica muscular.

Los procedimientos más utilizados son:

  • estandarización (z-score);
  • escalado Min-Max;
  • escalado robusto.

5.1 ¿Qué es la señal de respiración?

La señal de respiración (RESP) representa la dinámica del proceso respiratorio a lo largo del tiempo. Refleja la expansión y contracción del tórax o del abdomen durante los ciclos de inspiración y espiración.

En estudios psicofisiológicos, la respiración es una de las señales más relevantes porque está estrechamente relacionada con la actividad del sistema nervioso autónomo, el estrés, la relajación y la carga cognitiva.

5.2 Fisiología básica de la respiración

La respiración tiene como objetivo principal el intercambio de oxígeno (O₂) y dióxido de carbono (CO₂).

Cada ciclo respiratorio comprende dos fases:

  • Inspiración: entrada de aire a los pulmones.
  • Espiración: salida de aire hacia el exterior.

El diafragma y los músculos intercostales coordinan este proceso mediante contracciones rítmicas.

5.3 Regulación de la respiración

El ritmo respiratorio está regulado por centros neuronales situados en el tronco encefálico.

Sin embargo, también puede modificarse por:

  • emociones;
  • estrés;
  • ejercicio físico;
  • atención;
  • sueño;
  • habla.

Esta interacción convierte a la respiración en un excelente indicador del estado fisiológico.

5.4 Respiración y sistema nervioso autónomo

La frecuencia respiratoria cambia continuamente como respuesta al equilibrio entre el sistema nervioso simpático y el parasimpático.

En situaciones de estrés suele observarse:

  • aumento de la frecuencia respiratoria;
  • respiraciones más superficiales;
  • menor variabilidad entre ciclos.

En estados de relajación ocurre generalmente el patrón contrario.

Características principales:

  • frecuencia de muestreo: 700 Hz;
  • sincronización con ECG, EDA, EMG, temperatura y acelerometría;
  • registro continuo durante todas las condiciones experimentales.

5.43 Introducción a las características no lineales

Estas medidas son especialmente útiles cuando los patrones respiratorios cambian debido al estrés, la ansiedad, la carga cognitiva o alteraciones del control autonómico.

5.44 Approximate Entropy (ApEn)

¿Qué mide?

La Approximate Entropy (ApEn) evalúa el grado de regularidad de una serie temporal.

Una señal con respiraciones muy repetitivas presenta una entropía baja, mientras que una señal con mayor irregularidad produce valores más elevados.

Interpretación

  • ApEn baja → respiración muy regular.
  • ApEn alta → respiración más impredecible.

Ventajas

  • Fácil interpretación.
  • Amplio uso en fisiología.

Limitaciones

  • Sensible al número de muestras.
  • Depende de los parámetros seleccionados.

5.45 Sample Entropy (SampEn)

La Sample Entropy constituye una mejora de la Approximate Entropy.

A diferencia de ApEn:

  • reduce el sesgo estadístico;
  • elimina las auto-coincidencias;
  • proporciona estimaciones más estables.

Por estas razones es una de las medidas de complejidad más utilizadas en bioseñales.

5.46 Permutation Entropy

La Permutation Entropy cuantifica la complejidad analizando el orden relativo de los valores de la señal, en lugar de sus amplitudes absolutas.

Ventajas:

  • robusta frente al ruido;
  • bajo coste computacional;
  • adecuada para señales fisiológicas largas.

Aplicaciones:

  • análisis respiratorio;
  • electroencefalografía;
  • ECG;
  • EMG;
  • detección de estados cognitivos.

5.47 Spectral Entropy

La Spectral Entropy se calcula a partir de la distribución de potencia del espectro.

Una señal cuya energía se concentra en pocas frecuencias presenta una entropía espectral baja.

Si la energía está distribuida entre muchas frecuencias, la entropía aumenta.

Esta característica resume el grado de organización del contenido frecuencial.

5.48 Detrended Fluctuation Analysis (DFA)

El Detrended Fluctuation Analysis (DFA) estudia las correlaciones de largo alcance dentro de una serie temporal.

En respiración permite evaluar cómo evolucionan las fluctuaciones respiratorias a diferentes escalas temporales.

El exponente obtenido refleja el comportamiento fractal de la señal.

5.49 Exponente de Hurst

El Exponente de Hurst (H) describe la persistencia temporal de una serie.

Interpretación habitual:

  • H ≈ 0.5 → comportamiento aleatorio.
  • H > 0.5 → persistencia.
  • H < 0.5 → antipersistencia.

Esta medida ayuda a caracterizar la organización temporal de los ciclos respiratorios.

5.50 Recurrence Quantification Analysis (RQA)

La Recurrence Quantification Analysis estudia la recurrencia de los estados dinámicos de un sistema mediante diagramas de recurrencia.

Algunas métricas habituales incluyen:

  • Recurrence Rate (RR);
  • Determinism (DET);
  • Laminarity (LAM);
  • Entropy (ENTR).

Estas variables permiten describir la estructura dinámica de la respiración más allá de los métodos lineales.

5.51 Aplicaciones en WESAD

Las características no lineales complementan las medidas temporales y espectrales al capturar cambios sutiles en la organización de la respiración.

Su combinación con las features de ECG, EDA y EMG mejora la capacidad de los modelos para distinguir entre estados de relajación, estrés y diversión.

6.1 Introducción

La temperatura periférica de la piel (TEMP) es una bioseñal que refleja los cambios térmicos producidos por la perfusión sanguínea cutánea y por la actividad del sistema nervioso autónomo.

Aunque suele variar lentamente, aporta información valiosa sobre la respuesta fisiológica al estrés, la relajación, la actividad física y los procesos de termorregulación.

flowchart LR
A[Sistema nervioso autónomo]
-->B[Vasoconstricción / Vasodilatación]

6.2 ¿Qué mide la señal TEMP?

La señal TEMP registra la temperatura superficial de la piel en un punto específico del cuerpo. En el conjunto de datos WESAD, esta medida se adquiere de forma continua y sincronizada con el resto de bioseñales.

No representa la temperatura corporal central, sino la temperatura periférica, que es mucho más sensible a los cambios en la circulación sanguínea y al control autonómico.

6.3 Fundamentos fisiológicos

La temperatura cutánea depende principalmente de:

  • flujo sanguíneo periférico;
  • temperatura ambiental;
  • sudoración;
  • metabolismo;
  • actividad del sistema nervioso simpático.

En situaciones de estrés suele producirse vasoconstricción periférica, reduciendo el flujo de sangre hacia la piel y provocando un descenso gradual de la temperatura en determinadas zonas corporales.

6.4 Termorregulación

La termorregulación mantiene la temperatura corporal dentro de un rango compatible con el funcionamiento normal del organismo.

Los principales mecanismos son:

  • vasodilatación;
  • vasoconstricción;
  • sudoración;
  • temblor muscular;

Por este motivo, la temperatura suele utilizarse como una señal complementaria junto con ECG, EDA, EMG y RESP.

Características generales:

  • frecuencia de muestreo: 700 Hz;
  • adquisición continua;
  • sincronización temporal con ECG, EDA, EMG, RESP y ACC.

Aunque es una señal estable, TEMP puede verse afectada por:

  • estabilidad del sensor;
  • sincronización con el resto de bioseñales.

Debido a la naturaleza lenta de la señal, suelen emplearse técnicas de suavizado para reducir pequeñas fluctuaciones de alta frecuencia.

  • filtro de mediana;
  • filtro de Savitzky–Golay;
  • filtros pasa-bajos cuando son apropiados.

El objetivo es preservar la evolución térmica global.

En registros prolongados pueden observarse cambios lentos en la línea base debidos al entorno o a variaciones del sensor.

La corrección de esta deriva permite comparar ventanas temporales de forma más consistente y mejora la interpretación de las características.

Las características temporales describen el comportamiento de la temperatura directamente en el dominio del tiempo. Debido a que la temperatura cutánea cambia lentamente, estas variables suelen ser suficientes para capturar gran parte de la información fisiológica relevante.

6.17 Temperatura media (Mean)

¿Qué mide?

La temperatura media representa el valor promedio de todas las muestras de una ventana.

[ {T}=_{i=1}^{N}T_i ]

Interpretación fisiológica

Refleja el nivel térmico basal de la piel durante el periodo analizado.

  • Valores altos: mayor perfusión periférica.
  • Valores bajos: posible vasoconstricción o menor flujo sanguíneo.

6.18 Temperatura mediana (Median)

La mediana corresponde al valor central de la distribución de temperaturas.

Ventajas

  • Robusta frente a valores atípicos.
  • Menor influencia de artefactos puntuales.
  • Adecuada para registros prolongados.

6.19 Temperatura mínima (Minimum)

La temperatura mínima identifica el valor más bajo registrado en una ventana.

Puede utilizarse para detectar episodios de enfriamiento periférico asociados con respuestas de estrés o cambios en la circulación.

6.20 Temperatura máxima (Maximum)

La temperatura máxima representa el mayor valor observado durante la ventana.

Su comparación con la temperatura mínima permite estimar la amplitud de las variaciones térmicas.

6.21 Rango térmico (Range)

El rango térmico mide la diferencia entre la temperatura máxima y la mínima.

[ Range = T_{max} - T_{min} ]

Interpretación

  • Rango pequeño: señal muy estable.
  • Rango grande: mayor variabilidad térmica.

6.22 Pendiente (Slope)

La pendiente describe la tendencia general de la temperatura.

Puede estimarse mediante una regresión lineal sobre la ventana.

  • Pendiente positiva: incremento progresivo.
  • Pendiente negativa: descenso progresivo.

Esta característica resulta especialmente útil para detectar cambios lentos inducidos por el estrés.

6.23 Tasa de cambio (Rate of Change)

La tasa de cambio cuantifica la rapidez con la que varía la temperatura.

[ ROC= ]

Valores cercanos a cero indican estabilidad térmica, mientras que magnitudes mayores reflejan transiciones más rápidas.

6.24 Desviación estándar y varianza

La desviación estándar y la varianza resumen la dispersión de las temperaturas dentro de una ventana.

Estas medidas permiten evaluar la estabilidad de la señal y complementar la información aportada por la media y el rango térmico.

6.26 Coeficiente de variación (CV)

El coeficiente de variación relaciona la desviación estándar con la media.

[ CV= ]

Permite comparar la variabilidad relativa entre sujetos con diferentes temperaturas basales.

Interpretación

  • CV bajo: señal muy estable.
  • CV alto: mayor variabilidad térmica.

6.27 Percentiles

Los percentiles describen la posición relativa de los valores de temperatura.

Los más utilizados son:

  • P25: primer cuartil.
  • P50: mediana.
  • P75: tercer cuartil.

Estas medidas son robustas frente a valores atípicos y complementan la media.

6.28 Rango intercuartílico (IQR)

El IQR cuantifica la dispersión de la mitad central de los datos.

[ IQR=P75-P25 ]

Un IQR pequeño indica una temperatura estable, mientras que un IQR elevado refleja una mayor dispersión de los valores.

6.29 Asimetría (Skewness)

La asimetría mide el grado de simetría de la distribución.

  • Asimetría ≈ 0: distribución simétrica.
  • Asimetría positiva: cola hacia valores altos.
  • Asimetría negativa: cola hacia valores bajos.

Puede revelar cambios térmicos poco frecuentes dentro de una ventana.

6.30 Curtosis (Kurtosis)

La curtosis describe el grado de concentración de los datos alrededor de la media.

  • Curtosis alta: presencia de picos pronunciados.
  • Curtosis baja: distribución más plana.

Esta medida ayuda a detectar distribuciones inusuales de la temperatura.

6.31 Estabilidad térmica

La estabilidad térmica resume cuánto fluctúa la temperatura durante un intervalo.

Puede estimarse mediante una combinación de:

  • desviación estándar;
  • coeficiente de variación;
  • IQR;
  • rango térmico.

Una elevada estabilidad suele corresponder a cambios fisiológicos lentos y consistentes.

6.32 Tendencias de largo plazo

En registros prolongados resulta útil analizar la tendencia general de la temperatura mediante:

  • pendiente acumulada;
  • regresión lineal;
  • medias móviles.

Estas variables permiten identificar incrementos o descensos progresivos relacionados con la respuesta fisiológica.

6.33 Aplicaciones en WESAD

Combinadas con ECG, EDA, EMG y RESP mejoran la representación multimodal del estado fisiológico.

6.34 Introducción al análisis espectral

Aunque la temperatura cutánea es una señal de muy baja frecuencia, el análisis espectral puede aportar información sobre la distribución de su energía y sobre la presencia de componentes periódicas de origen fisiológico o ambiental.

A diferencia de señales como ECG o EMG, la mayor parte de la potencia de TEMP se concentra en las frecuencias más bajas.

6.35 ¿Cuándo es útil el análisis espectral?

El análisis en frecuencia resulta especialmente útil cuando se desea:

  • estudiar oscilaciones lentas de la temperatura;
  • comparar patrones térmicos entre sujetos;
  • analizar cambios fisiológicos prolongados;
  • complementar las características temporales.

Debe interpretarse teniendo en cuenta que TEMP presenta una dinámica mucho más lenta que otras bioseñales.

6.36 Transformada Rápida de Fourier (FFT)

La Fast Fourier Transform (FFT) convierte la señal del dominio temporal al dominio de la frecuencia.

Esto permite identificar las frecuencias predominantes presentes en la señal térmica.

En la señal TEMP, el espectro suele concentrarse en frecuencias muy bajas.

6.37 Densidad Espectral de Potencia (PSD)

La Power Spectral Density (PSD) describe cómo se distribuye la energía de la señal entre las diferentes frecuencias.

Habitualmente se estima mediante el método de Welch, ya que proporciona estimaciones más estables al promediar varios segmentos parcialmente solapados.

La PSD constituye la base para múltiples características espectrales.

6.38 Potencia espectral total

La potencia espectral total corresponde al área bajo la curva de la PSD.

Representa la energía global de la señal durante la ventana analizada.

Interpretación

  • Potencia alta: mayor variabilidad térmica.
  • Potencia baja: temperatura más estable.

Esta característica debe interpretarse junto con la pendiente y la variabilidad temporal.

6.40 Centroide espectral

El centroide espectral representa el centro de gravedad del espectro de potencia.

Valores elevados indican una mayor contribución relativa de componentes de frecuencia más alta, mientras que valores bajos reflejan una concentración de energía en frecuencias muy lentas.

6.41 Limitaciones del análisis espectral

El análisis espectral de la temperatura presenta varias limitaciones:

  • baja dinámica de la señal;
  • escasa presencia de componentes rápidas;
  • influencia del entorno;
  • cambios muy lentos durante el registro.

Por ello, en muchos estudios las características temporales tienen un mayor peso que las espectrales.

Su integración con ECG, EDA, EMG y RESP mejora la capacidad de los modelos para discriminar entre estados de relajación, diversión y estrés.

6.44 Approximate Entropy (ApEn)

La Approximate Entropy (ApEn) mide el grado de regularidad de una serie temporal.

Interpretación

  • ApEn baja: comportamiento muy regular.
  • ApEn alta: mayor irregularidad y complejidad.

Ventajas

  • Fácil interpretación.
  • Muy utilizada en bioseñales.

Limitaciones

  • Sensible a la longitud de la señal.
  • Depende de los parámetros de cálculo.

6.45 Sample Entropy (SampEn)

La Sample Entropy reduce el sesgo presente en ApEn al eliminar las autocoincidencias.

Sus principales ventajas son:

  • mayor estabilidad estadística;
  • mejor comportamiento con registros fisiológicos;
  • amplia utilización en investigación biomédica.

6.46 Permutation Entropy

La Permutation Entropy evalúa la complejidad mediante el orden relativo de las muestras, sin depender directamente de sus amplitudes.

Es especialmente robusta frente al ruido y adecuada para señales largas con variaciones suaves, como la temperatura cutánea.

6.47 Spectral Entropy

La Spectral Entropy se calcula a partir de la distribución de potencia del espectro.

  • Valores bajos indican energía concentrada en pocas frecuencias.
  • Valores altos reflejan una distribución más uniforme de la energía.

En TEMP suele presentar valores moderados debido al predominio de componentes lentas.

6.48 Detrended Fluctuation Analysis (DFA)

El Detrended Fluctuation Analysis (DFA) analiza la existencia de correlaciones de largo alcance dentro de la señal.

Permite estudiar si las fluctuaciones térmicas mantienen un comportamiento persistente a diferentes escalas temporales.

6.49 Exponente de Hurst

El Exponente de Hurst (H) caracteriza la persistencia temporal.

Interpretación habitual:

  • H ≈ 0.5: comportamiento aleatorio.
  • H > 0.5: persistencia.
  • H < 0.5: antipersistencia.

Esta métrica ayuda a describir la estabilidad de la regulación térmica.

6.50 Recurrence Quantification Analysis (RQA)

La RQA estudia la estructura dinámica de la señal mediante diagramas de recurrencia.

Las medidas más empleadas incluyen:

  • Recurrence Rate (RR);
  • Determinism (DET);
  • Laminarity (LAM);
  • Entropy (ENTR).

Estas variables complementan las medidas lineales y permiten analizar la organización de la dinámica térmica.

6.51 Aplicaciones en WESAD

Aunque las características no lineales de TEMP son menos frecuentes que en ECG o EDA, constituyen un complemento útil cuando se combinan con otras bioseñales.

Su integración con ECG, EDA, EMG, RESP y ACC permite construir representaciones multimodales más ricas para la clasificación de estados fisiológicos.

7.10 Calibración del acelerómetro

La calibración corrige pequeños errores introducidos por el sensor durante la adquisición.

  • compensar diferencias entre ejes;

Las señales ACC pueden verse afectadas por:

  • filtros pasa-bajos;

  • filtros pasa-banda;

La elección depende del tipo de actividad y del contenido frecuencial de interés.

El coeficiente de variación (CV) relaciona la desviación estándar con la media.

Interpretación

  • CV bajo: movimiento uniforme.
  • CV alto: movimiento muy variable.

Permite comparar ventanas con diferentes niveles de aceleración.

7.29 Percentiles

Los percentiles describen la distribución de las aceleraciones.

Los más utilizados son:

  • P25 (primer cuartil),
  • P50 (mediana),
  • P75 (tercer cuartil).

Estas medidas son robustas frente a valores extremos y resumen la distribución del movimiento.

7.30 Rango intercuartílico (IQR)

El IQR mide la dispersión de la mitad central de las observaciones.

[ IQR=P75-P25 ]

Valores elevados indican una mayor variabilidad en la intensidad del movimiento.

7.31 Asimetría (Skewness)

La asimetría cuantifica la simetría de la distribución.

  • Skewness ≈ 0: distribución simétrica.
  • Skewness > 0: predominan aceleraciones altas.
  • Skewness < 0: predominan aceleraciones bajas.

Puede ayudar a detectar movimientos bruscos poco frecuentes.

7.32 Curtosis (Kurtosis)

La curtosis mide el grado de concentración de las muestras alrededor de la media.

  • Curtosis alta: presencia de picos pronunciados.
  • Curtosis baja: distribución más uniforme.

Es útil para identificar impactos o movimientos impulsivos.

7.33 Jerk

El Jerk es la derivada temporal de la aceleración y representa la rapidez con la que cambia la aceleración.

[ Jerk= ]

Aplicaciones

  • detección de movimientos bruscos;
  • análisis biomecánico;
  • reconocimiento de gestos;
  • cuantificación de suavidad del movimiento.

7.34 Zero Crossing Rate (ZCR)

El Zero Crossing Rate (ZCR) indica cuántas veces la señal cruza el valor cero dentro de una ventana.

Una elevada tasa de cruces suele asociarse con movimientos rápidos, vibraciones o señales de alta frecuencia.

7.35 Índices de estabilidad del movimiento

La estabilidad del movimiento puede resumirse combinando varias medidas:

  • desviación estándar;
  • coeficiente de variación;
  • IQR;
  • Jerk;
  • ZCR.

Estos índices ayudan a diferenciar actividades suaves de movimientos intensos o erráticos.

7.47 Approximate Entropy (ApEn)

La Approximate Entropy (ApEn) mide el grado de regularidad de una serie temporal.

Interpretación

  • ApEn baja: movimientos repetitivos y predecibles.
  • ApEn alta: movimientos complejos o variables.

Aplicaciones:

  • análisis de actividad humana;
  • evaluación de patrones motores;
  • diferenciación entre movimiento estable e inestable.

7.48 Sample Entropy (SampEn)

La Sample Entropy (SampEn) es una mejora de ApEn al reducir el sesgo asociado al tamaño de la muestra.

Ventajas:

  • mayor estabilidad;
  • menor dependencia del número de muestras;
  • ampliamente utilizada en señales fisiológicas.

7.49 Permutation Entropy

La Permutation Entropy evalúa la complejidad considerando el orden relativo de las muestras en la señal.

Sus principales ventajas son:

  • robustez frente al ruido;
  • bajo coste computacional;
  • adecuada para ventanas cortas.

7.50 Spectral Entropy

La entropía espectral mide la incertidumbre de la distribución de energía en el dominio de la frecuencia.

  • Valores bajos: energía concentrada.
  • Valores altos: energía distribuida en múltiples frecuencias.

7.51 Detrended Fluctuation Analysis (DFA)

El DFA analiza correlaciones de largo alcance eliminando previamente las tendencias de la señal.

Permite estudiar:

  • persistencia del movimiento;
  • organización temporal;
  • comportamiento fractal.

7.52 Exponente de Hurst

El exponente de Hurst (H) cuantifica la memoria temporal de la señal.

Interpretación:

  • H ≈ 0.5: comportamiento aleatorio.
  • H > 0.5: persistencia.
  • H < 0.5: comportamiento antipersistente.

7.53 Recurrence Quantification Analysis (RQA)

La RQA analiza las recurrencias del sistema dinámico.

Medidas frecuentes:

  • Recurrence Rate (RR).
  • Determinism (DET).
  • Laminarity (LAM).
  • Trapping Time (TT).

Estas variables ayudan a caracterizar la estabilidad del movimiento.

7.54 Aplicaciones en WESAD

Las características no lineales permiten:

  • diferenciar patrones motores complejos;
  • detectar cambios sutiles en la dinámica del movimiento;
  • complementar las características temporales y espectrales;
  • mejorar modelos multimodales para clasificación de estrés.

Para construir un conjunto de datos multimodal es indispensable que todas las señales representen el mismo intervalo temporal.

La sincronización garantiza que cada ventana de ECG, EDA, EMG, RESP, TEMP y ACC corresponda al mismo instante fisiológico del participante.

8.8 ¿Por qué es importante?

Si las señales no están alineadas temporalmente:

  • las características no describen el mismo evento;
  • disminuye el rendimiento del modelo;
  • aparecen relaciones espurias entre variables;
  • aumenta el riesgo de errores durante el entrenamiento.

Una correcta sincronización mejora la calidad del dataset y la capacidad predictiva.

  • interpolación lineal;
  • interpolación por splines.

  • mejora la estabilidad numérica;

  • mejorar la interpretabilidad;
  • reducir el tiempo de entrenamiento.

Los métodos Filter evalúan cada característica de forma independiente.

Ejemplos:

  • información mutua;
  • ANOVA;

  • Sequential Backward Selection.

Los métodos Embedded realizan la selección durante el entrenamiento.

  • Random Forest;

  • dificultar la interpretación;

8.31 Reducción de dimensionalidad

8.32 ¿Por qué reducir la dimensionalidad?

Entre los principales beneficios se encuentran:

  • disminuir el riesgo de sobreajuste;
  • reducir el tiempo de entrenamiento;
  • facilitar la visualización de los datos;
  • eliminar redundancias;
  • mejorar la interpretabilidad del conjunto de características.

8.33 Análisis de Componentes Principales (PCA)

El Principal Component Analysis (PCA) transforma las variables originales en un nuevo conjunto de componentes ortogonales que explican la mayor parte de la varianza.

Ventajas

  • método rápido;
  • ampliamente utilizado;
  • sencillo de interpretar;
  • útil para exploración y preprocesamiento.

Limitaciones

  • captura únicamente relaciones lineales;
  • los componentes pueden ser difíciles de interpretar fisiológicamente.

8.34 Kernel PCA

El Kernel PCA extiende PCA utilizando funciones kernel para representar relaciones no lineales entre las variables.

Es especialmente útil cuando la estructura de los datos no puede describirse mediante una transformación lineal.

8.35 t-SNE

El algoritmo t-distributed Stochastic Neighbor Embedding (t-SNE) se utiliza principalmente para visualizar conjuntos de datos de alta dimensionalidad.

Características:

  • conserva vecindades locales;
  • excelente para exploración visual;
  • no está pensado para generar variables de entrada para un clasificador.

8.36 UMAP

El algoritmo Uniform Manifold Approximation and Projection (UMAP) permite reducir la dimensionalidad preservando tanto la estructura local como parte de la estructura global.

Ventajas:

  • rápido;
  • escalable;
  • adecuado para grandes conjuntos de datos;
  • útil para visualización y exploración.

8.38 ¿Cuándo utilizar cada técnica?

  • PCA: cuando se desea reducir variables antes del entrenamiento.
  • Kernel PCA: si existen relaciones no lineales.
  • t-SNE: para inspeccionar agrupamientos o separaciones entre clases.
  • UMAP: para explorar grandes volúmenes de datos con buena conservación de la estructura.

8.40 Estrategias de validación

La evaluación correcta de un modelo es tan importante como su entrenamiento. Una estrategia de validación adecuada permite estimar de forma realista la capacidad de generalización del modelo.

flowchart LR
A[Dataset] --> B[Entrenamiento]
A --> C[Validación]
A --> D[Prueba]

8.41 Hold-Out

La estrategia Hold-Out divide el conjunto de datos en entrenamiento y prueba.

Ventajas

  • Muy sencilla.
  • Bajo coste computacional.

Limitaciones

  • Alta dependencia de una única partición.
  • Mayor variabilidad en los resultados.

8.42 Validación cruzada (k-Fold)

En k-Fold Cross Validation, el conjunto de datos se divide en k particiones.

Cada partición actúa una vez como validación mientras las restantes se utilizan para entrenar.

Beneficios:

  • mejor aprovechamiento de los datos;
  • estimaciones más estables;
  • menor dependencia de una única división.

8.43 Stratified k-Fold

Cuando existen clases desbalanceadas, Stratified k-Fold mantiene la proporción de cada clase en todas las particiones.

Esto reduce el riesgo de obtener subconjuntos poco representativos.

8.44 Leave-One-Subject-Out (LOSO)

En LOSO, todas las ventanas de un sujeto se reservan como conjunto de prueba y el modelo se entrena con el resto de participantes.

flowchart TD
A[S1] --> Train
B[S2] --> Train
C[S3] --> Test
D[S4] --> Train

Es la estrategia más recomendada para WESAD porque evalúa la capacidad de generalización hacia personas no vistas durante el entrenamiento.

8.45 Leave-One-Group-Out (LOGO)

LOGO generaliza el enfoque anterior permitiendo definir grupos completos (por ejemplo, participantes, sesiones o dispositivos) como unidad de validación.

Es especialmente útil cuando existen dependencias entre observaciones.

8.46 Prevención del Data Leakage

El data leakage ocurre cuando el modelo recibe, directa o indirectamente, información del conjunto de prueba durante el entrenamiento.

Buenas prácticas:

  • dividir los sujetos antes del preprocesamiento dependiente de los datos;
  • ajustar escaladores únicamente con entrenamiento;
  • realizar selección de características dentro de cada iteración de validación;
  • evitar mezclar ventanas del mismo sujeto entre entrenamiento y prueba.

8.47 Desbalance de clases

Cuando una clase tiene muchas más observaciones que otra, pueden utilizarse estrategias como:

  • ponderación de clases;
  • sobremuestreo (SMOTE y variantes);
  • submuestreo controlado;
  • métricas robustas como F1-score o Balanced Accuracy.

8.48 Recomendaciones para WESAD

Para obtener resultados reproducibles:

  • utilizar LOSO como evaluación principal;
  • fijar semillas aleatorias;
  • documentar todos los hiperparámetros;
  • repetir los experimentos cuando sea necesario;
  • reportar varias métricas y no solo la exactitud.

9.8 Regresión Logística

La Regresión Logística (Logistic Regression) es uno de los clasificadores supervisados más utilizados para problemas de clasificación binaria. Aunque su nombre contiene la palabra “regresión”, su objetivo es estimar la probabilidad de pertenencia a una clase.

-->E[Clase]

9.9 Modelo matemático

El modelo calcula primero una combinación lineal de las características:

[ z=_0+_1x_1+_2x_2++_nx_n ]

Posteriormente transforma ese valor en una probabilidad mediante la función sigmoide.

9.10 Función sigmoide

La función logística está definida por:

[ (z)= ]

Sus propiedades principales son:

  • salida entre 0 y 1;
  • interpretación probabilística;
  • transición suave entre clases.

9.11 Regla de decisión

En clasificación binaria suele emplearse un umbral de 0.5.

  • Probabilidad ≥ 0.5 → Estrés.
  • Probabilidad < 0.5 → No estrés.

Este umbral puede modificarse según el problema y las métricas de interés.

9.12 Función de pérdida

La Regresión Logística optimiza normalmente la Log Loss o Binary Cross-Entropy.

[ L=-1N_{i=1}^{N}]

Esta función penaliza con mayor intensidad las predicciones muy seguras que resultan incorrectas.

9.13 Regularización

Para reducir el sobreajuste se utilizan técnicas de regularización.

L1 (LASSO)

  • Favorece modelos dispersos.
  • Puede eliminar variables poco relevantes.

L2 (Ridge)

  • Reduce el tamaño de los coeficientes.
  • Mantiene todas las variables en el modelo.

  • Fácil de interpretar.

  • Buen rendimiento como modelo base.
  • Produce probabilidades directamente.

9.17 k-Nearest Neighbors (k-NN)

El algoritmo k-Nearest Neighbors (k-NN) clasifica una nueva observación utilizando las etiquetas de sus k vecinos más cercanos en el espacio de características.

9.18 Fundamento

k-NN es un algoritmo basado en instancias: no construye un modelo explícito, sino que almacena los datos de entrenamiento y compara cada nueva muestra con ellos.

9.20 Elección del parámetro k

9.26 Support Vector Machines (SVM)

Las Support Vector Machines (SVM) son algoritmos supervisados que buscan el hiperplano que separa las clases maximizando el margen entre ellas.

9.27 Hiperplano y margen

Para un problema binario, una SVM intenta encontrar el hiperplano:

[ w^Tx+b=0 ]

que maximiza la distancia entre las observaciones de distintas clases. Los ejemplos más cercanos al hiperplano reciben el nombre de vectores de soporte.

9.28 Vectores de soporte

No todas las muestras influyen en el modelo. La frontera de decisión está determinada principalmente por los vectores de soporte, lo que hace a las SVM robustas frente a muchos datos redundantes.

9.29 Kernels

Cuando las clases no son linealmente separables, pueden utilizarse funciones kernel para proyectar los datos a un espacio de mayor dimensión.

Los kernels más utilizados son:

  • Lineal.
  • Polinómico.
  • RBF (Radial Basis Function).
  • Sigmoide.

9.30 Parámetros principales

Parámetro C

Controla el equilibrio entre un margen amplio y los errores de clasificación.

  • C alto: menor tolerancia al error.
  • C bajo: mayor regularización.

Parámetro γ (gamma)

Especialmente importante con el kernel RBF.

  • γ alto: fronteras muy complejas.
  • γ bajo: fronteras más suaves.

9.31 Ventajas

  • Excelente rendimiento en conjuntos de tamaño medio.
  • Muy eficaces en espacios de alta dimensión.
  • Funcionan bien con muchas características.

9.32 Limitaciones

  • Mayor coste computacional que modelos lineales.
  • Sensibles a la selección de hiperparámetros.
  • Menor interpretabilidad que otros clasificadores.

9.34 Árboles de Decisión

Los Árboles de Decisión (Decision Trees) son modelos supervisados que dividen el espacio de características mediante reglas sucesivas hasta llegar a una predicción.

flowchart TD
A[¿EDA > umbral?]
--> |Sí| B[¿HRV baja?]
--> |Sí| C[Estrés]
B --> |No| D[No estrés]
A --> |No| D

9.35 Estructura de un árbol

Un árbol está compuesto por:

  • Nodo raíz: primera división.
  • Nodos internos: reglas de decisión.
  • Hojas: clase final predicha.

Cada división intenta aumentar la homogeneidad de las observaciones.

9.36 Criterios de división

Índice de Gini

Mide la impureza de un nodo:

[ G = 1 - _{i=1}^{K} p_i^2 ]

Cuanto menor sea el índice de Gini, más homogéneo será el nodo.

Entropía

Basada en la teoría de la información:

[ H = -_{i=1}^{K} p_i _2(p_i) ]

Ambos criterios buscan encontrar la división que mejor separa las clases.

9.37 Sobreajuste

Los árboles muy profundos pueden memorizar el conjunto de entrenamiento y perder capacidad de generalización.

Para reducir este problema se emplean estrategias como:

  • limitar la profundidad máxima;
  • establecer un número mínimo de muestras por nodo;
  • restringir el número mínimo de muestras por hoja.

9.38 Poda (Pruning)

La poda elimina ramas poco útiles para simplificar el modelo.

Beneficios:

  • menor complejidad;
  • mejor capacidad de generalización;
  • reducción del sobreajuste.

9.39 Importancia de variables

Los árboles permiten estimar la contribución relativa de cada característica.

En WESAD esta información ayuda a identificar qué variables fisiológicas (EDA, ECG, RESP, etc.) aportan mayor capacidad discriminativa para detectar estrés.

9.40 Ventajas

  • Fácil interpretación.
  • No requiere escalado obligatorio.
  • Captura relaciones no lineales.
  • Admite variables de distinta naturaleza.

9.41 Limitaciones

  • Sensible a pequeñas variaciones en los datos.
  • Riesgo de sobreajuste.
  • Menor estabilidad que los métodos de ensamble.

9.42 Aplicaciones en WESAD

Buenas prácticas:

  • controlar la profundidad del árbol;
  • validar mediante LOSO;
  • comparar con modelos lineales y de ensamble;
  • analizar la importancia de las características.

9.43 Random Forest

Random Forest es un algoritmo de ensamble que combina múltiples árboles de decisión para obtener un modelo más robusto, preciso y estable que un árbol individual.

9.44 Bootstrap Aggregating (Bagging)

Cada árbol se entrena con una muestra aleatoria del conjunto de entrenamiento obtenida mediante bootstrap (muestreo con reemplazo).

Ventajas:

  • Reduce la varianza.
  • Disminuye el sobreajuste.
  • Incrementa la estabilidad del modelo.

9.45 Selección aleatoria de características

En cada división del árbol solo se evalúa un subconjunto aleatorio de variables.

Esto favorece la diversidad entre árboles y mejora la capacidad de generalización.

9.46 Predicción por votación

En clasificación, cada árbol emite una predicción y la clase final se determina mediante votación mayoritaria.

En problemas de regresión se utiliza el promedio de las predicciones.

9.47 Importancia de variables

Random Forest permite estimar la importancia relativa de cada característica.

Las técnicas más utilizadas son:

  • Disminución media de la impureza (MDI).

9.54 Gradient Boosting Machine (GBM)

En GBM cada nuevo árbol aproxima el gradiente negativo de la función de pérdida, mejorando progresivamente las predicciones.

Ventajas:

  • Modela relaciones complejas.

Es uno de los algoritmos más utilizados en competiciones y aplicaciones biomédicas.

9.56 LightGBM

  • Bajo consumo de memoria.

9.57 CatBoost

9.61 Redes Neuronales Multicapa (MLP)

Las Multilayer Perceptron (MLP) son redes neuronales artificiales formadas por múltiples capas de neuronas conectadas. Constituyen uno de los modelos fundamentales del aprendizaje profundo y pueden aproximar relaciones altamente no lineales.

9.62 El perceptrón

El perceptrón calcula una combinación lineal de las entradas seguida de una función de activación.

[ z=_{i=1}^{n} w_i x_i+b ]

La salida se obtiene aplicando una función no lineal sobre (z).

9.63 Arquitectura de una MLP

Una red MLP está compuesta por:

  • Capa de entrada: recibe las características.
  • Capas ocultas: aprenden representaciones internas.
  • Capa de salida: produce la predicción.

El número de capas y neuronas depende de la complejidad del problema.

9.66 Retropropagación

La backpropagation calcula el gradiente de la función de pérdida respecto a cada peso y actualiza los parámetros para reducir el error.

Este proceso se repite durante múltiples épocas (epochs).

[ w_{nuevo}=w_{anterior}- ]

donde:

  • (L) es la función de pérdida;
  • (w) representa un peso;
  • () es la tasa de aprendizaje (learning rate).

9.70 Optimización de hiperparámetros

Los hiperparámetros son configuraciones definidas antes del entrenamiento que controlan el comportamiento del algoritmo. A diferencia de los parámetros del modelo (pesos, coeficientes, etc.), no se aprenden automáticamente.

  • max_depth en árboles.
  • n_estimators en Random Forest.

Grid Search evalúa exhaustivamente todas las combinaciones posibles de un conjunto de hiperparámetros previamente definido.

  • Reproducible.

Desventajas

9.72 Random Search

En Random Search solo se evalúa un subconjunto aleatorio de configuraciones.

Ventajas:

  • Mucho más eficiente.
  • Explora regiones amplias del espacio.
  • Muy útil cuando existen muchos hiperparámetros.

9.73 Optimización Bayesiana

La optimización bayesiana construye un modelo probabilístico del rendimiento esperado y decide qué combinación evaluar a continuación.

Beneficios:

  • Reduce el número de evaluaciones.
  • Muy eficiente en problemas costosos.
  • Utilizada en bibliotecas como Optuna y Hyperopt.

L2

Reduce el tamaño de los coeficientes.

  • Analizar el comportamiento del modelo para sujetos concretos.

9.83 Partial Dependence Plots (PDP)

Los PDP muestran cómo cambia la predicción media del modelo al modificar una característica, manteniendo constantes las demás.

Son útiles para estudiar relaciones no lineales y comprender tendencias generales.

9.85 Selección del modelo

Al seleccionar un modelo conviene considerar:

  • tamaño del conjunto de datos;
  • número de características;
  • necesidad de interpretación;
  • tiempo disponible para entrenamiento;
  • restricciones computacionales;
  • facilidad de despliegue.

9.86 Buenas prácticas para experimentos reproducibles

Se recomienda:

  • fijar semillas aleatorias;
  • documentar versiones de software;
  • registrar hiperparámetros;
  • conservar particiones de entrenamiento y prueba;
  • publicar código cuando sea posible;
  • describir completamente el pipeline experimental.

9.87 Errores frecuentes

Los problemas más habituales incluyen:

  • fuga de información (data leakage);
  • validación incorrecta por ventanas en lugar de sujetos;
  • ausencia de escalado cuando el algoritmo lo requiere;
  • comparación de modelos con particiones diferentes;
  • uso de una única métrica de evaluación.

9.88 Conclusiones del capítulo

Los modelos de Machine Learning proporcionan herramientas eficaces para la clasificación del estrés utilizando señales fisiológicas. La selección del algoritmo debe basarse tanto en el rendimiento predictivo como en la interpretabilidad, la robustez y la reproducibilidad del experimento.

La combinación de una ingeniería de características adecuada, una validación rigurosa y una optimización cuidadosa de hiperparámetros constituye la base para construir sistemas fiables de detección automática del estrés.
